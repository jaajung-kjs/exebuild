# Plan 2 수동 통합 검증 (사내망 Windows)

전제: PowerGate 실행, 사내망 연결, `pip install -r requirements.txt`.

## 기동
- [ ] `python -m app.main` 실행 → 창이 뜨고 사이드바(①실행/②설정/③메일(베타)) 표시, 테마 적용됨
- [ ] (EXE) 실행 시 빈 cmd 콘솔 창이 뜨지 않음

## ① 실행 (허브)
- [ ] 본부 드롭다운이 지역/건설/본사 그룹으로 표시, 구분줄은 선택 불가
- [ ] 날짜가 기본값(오늘+offset)으로 채워짐
- [ ] 실행할 작업 체크박스: 1(필수·고정), 2(정렬·가공 저장), 3(메일 베타)
- [ ] **2 체크 해제 + [실행]** → 다운로드 후 "원본" 파일 저장 (가공 없음)
- [ ] **2 체크 + 프리셋 없음 + [실행]** → 다운로드 후 ②설정 화면으로 안내
- [ ] **프리셋 불러온 뒤 2 체크 + [실행]** → 다운로드~저장까지 한 번에(설정 화면 안 거침)
- [ ] **3 체크 + [실행]** → 저장 후 ③메일 화면으로 이동(수신자 등 프리셋값 반영)
- [ ] PowerGate 끄고 시도 → 재시도 후 실패 메시지 표시(크래시 없음)

## ② 설정 (편집)
- [ ] 컬럼 목록/미리보기(상위 20행)가 실제 데이터로 채워짐
- [ ] "리포트에 넣을 항목"(체크=포함) / 강조 규칙 문장 / 필터 문장(AND·OR) 동작
- [ ] 필터 조건: 비어있는·시작·끝·여러 값 중 하나(쉼표) 동작, not_null/is_empty는 값칸 비활성
- [ ] 색 버튼 → 색 선택기, 선택 색이 버튼에 반영
- [ ] [엑셀 저장] → 저장 후 [폴더 열기]/[메일로 보내기(베타)]/[닫기] 안내
- [ ] [원본 그대로 저장] → 가공 없이 저장
- [ ] 강조 규칙이 없으면 결과에 "점검순위" 열이 생기지 않음(원본 유지)
- [ ] 같은 파일을 엑셀로 열어둔 채 저장 → "파일 닫고 재시도" 안내(크래시 없음)
- [ ] 생성된 xlsx: 지사별 시트 분리, 순위 행 색, 헤더/테두리/틀고정/자동필터 확인

## ③ 메일 (베타·선택)
- [ ] 수신자 여러 명(줄바꿈) 입력, 제목/본문 {DATE} 치환 확인
- [ ] [발송] → 성공 시 완료, 실패 시 "엑셀은 저장됨" 안내

## 프리셋
- [ ] [현재 설정 저장] → 이름 입력 → presets/<이름>.json 생성
- [ ] 드롭다운에서 선택 후 [불러오기] → 본부·drop·규칙·필터·정렬·메일 전부 복원
- [ ] 다른 본부용 프리셋을 별도 저장 → 하나의 EXE로 본부 전환 확인

## 빌드
- [ ] `pyinstaller build_exe.spec` → `dist/KEPCO_RPA.exe` 생성
- [ ] EXE 실행 → 위 시나리오 반복, presets/ 폴더가 EXE 옆에 생성됨

## 엣지 케이스 (설계상 동작 — 버그 아님)
- [ ] 스테일 프리셋: 프리셋의 규칙/필터/정렬/분리 열이 현재 데이터에 없는 열을 가리키면, 콤보가 조용히 첫 열로 폴백된다(경고 없음). 다른 스키마의 데이터에 옛 프리셋을 적용할 때 주의.
- [ ] 시트 분리 열을 drop에도 포함시키면, 생성 결과는 "전체" 시트 하나만 나온다(분리 안 됨). 분리 열은 drop하지 말 것.
