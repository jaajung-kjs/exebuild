# KEPCO 공사현장 점검 우선순위 리스트 생성기

Work Monitor 점검 데이터를 내려받아, 원하는 규칙(강조·필터·정렬)으로 가공해 Excel로 저장하고,
선택적으로 BizMail로 발송하는 **대화형 데스크톱 앱**(사내망 Windows 단일 EXE).

## 실행 방법

```bash
pip install -r requirements.txt
python -m app.main          # 개발 실행
# 또는 배포된 KEPCO_RPA.exe 더블클릭
```

**사전 요구사항**: PowerGate 실행 중, KEPCO 사내망 접속.

## 사용 흐름

1. **② 설정 · ③ 메일** 탭에서 규칙·수신자를 정하고 **[설정 저장]** (한 번만 — 이후 자동 복원)
   - **② 설정**: 리포트에 넣을 항목, 강조 규칙(예: "공사명에 활선 포함 → 1순위 노란색"),
     필터(비어있지 않은/포함/여러 값 중 하나 등, AND·OR), 정렬, 지사별 시트 나누기
   - **③ 메일(베타)**: 발신·수신·제목·본문 (`{DATE}`는 대상 날짜로 치환)
2. **① 실행** 탭에서 날짜·본부를 고르고 실행할 작업을 체크한 뒤 **[▶ 실행]**
   - `1` 데이터 불러오기(필수) / `2` 정렬·가공해서 저장 / `3` 메일 발송(베타)
   - `2` 해제 → 원본 그대로 저장 · `2` 체크 → 설정 적용 저장 · `3` 체크 → 발송까지

## 설정 저장 (DRM 회피)

설정은 **파일이 아니라 Windows 레지스트리**(`HKEY_CURRENT_USER\Software\KEPCO\점검리스트생성기`)에
저장·자동복원된다. 새 파일을 만들지 않으므로 사내 DRM의 영향을 받지 않는다. 앱이 만드는 파일은
**결과 엑셀뿐**(다운로드는 메모리 처리).

## 출력

- 위치: 실행 파일과 같은 폴더
- 파일명: `YYMMDD 공사현장 점검 우선순위 리스트.xlsx` (원본 저장 시 `… 원본.xlsx`)
- 지사별 다중 시트 + 순위 행 색 + 헤더/테두리/틀고정/자동필터

## 빌드

```bash
pyinstaller build_exe.spec      # → dist/KEPCO_RPA.exe
```

`main` 브랜치에 푸시하면 GitHub Actions가 Windows EXE를 빌드해 아티팩트로 올린다.

## 개발

```bash
pytest -q                       # 순수 로직 단위 테스트 (사내망 불필요)
```
